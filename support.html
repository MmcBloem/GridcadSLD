Common questions

How should I use one iCloud drawing on two devices?

Save the drawing to iCloud Drive using the app’s file controls. Finish editing on the first device, confirm the drawing is saved and allow iCloud to sync before opening it on the second device. Avoid editing the same file on both devices at once. If the app reports that the file changed elsewhere, save a copy with a different name to preserve your changes before reopening the latest file.

How do I share my complete Library?

In Library, choose Export Entire Library and save the .gridLibrary file. On the other device, use Import Entire Library and select that file. Review its contents and duplicate options before importing. Skip keeps existing matching items; Keep Both creates additional items; Replace replaces matching items. Library package transfer requires Pro.

In versions that support file associations, opening a .gridLibrary file from Files or Finder also starts the import workflow. Existing .zip symbol packages can be imported through the Library’s Import command.

How do I restore GridCAD Pro?

Use the same Apple Account that originally purchased Pro and choose Restore Purchases on the Pro screen. An internet connection may be needed to contact Apple. The one-time unlock is a non-consumable purchase. If access is still missing, email support with the app version and the message shown; do not send payment-card details.

How do custom calculators work?

Open the Calculators tab, then Custom Calculators. Use Tutorial for the supported JSON format and instructions. Import the JSON file, check its inputs, assumptions and verification examples, and calculate. Where available, paste results into the drawing as a table snapshot. The snapshot does not update automatically when inputs change. Units are display labels; the calculator file must implement any unit conversion.

Check engineering formulas and source data independently before relying on a result. An imported file is not a certification or approval.

What can I do after a crash or a save problem?

Review available recovery copies through Recover Drawings. Save recovered work to Files for a durable copy. If the file changed elsewhere, use Save a Copy with a different name. Send support the steps that reproduce the issue and, if you choose, a diagnostic report exported from Diagnostics.

How do I manage camera and photo access?

Camera access is used when you choose Take Picture. Select images through the app’s photo controls. You can manage permissions in device Settings; core drawing remains available without camera or photo access.
